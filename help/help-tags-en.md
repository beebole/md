The tags section shows which tags this entity belongs to. Tagging groups entities together for shared settings, filtering, and reporting. Any settings configured on a tag — such as schedules, rates, notifications, or approval stages — are inherited by every entity that carries it. Add or remove tags to control which groups this entity is part of; removing a tag inherited from a parent project or task adds an exclusion here instead, shown as a red hatched badge that you remove to get the tag back.
