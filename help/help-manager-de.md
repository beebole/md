Dieser Bereich zeigt die Teammitglieder, Projekte, Aufgaben und Tags, die diese Person verwaltet, und unter „Geleitet von“, wer diese Person verwaltet. Wenn Sie eine ganze Kategorie auswählen, etwa eine Projektkategorie, eine Planung oder eine Tag-Kategorie, wird die Person Manager von allem darin, einschließlich später hinzugefügter Elemente; die Verwaltung eines Projekts umfasst auch seine Unterprojekte, und die Verwaltung eines Tags umfasst die damit getaggten Personen und Projekte. Manager können benachrichtigt werden, wenn von ihnen verwaltete Elemente erwähnt werden, und sie genehmigen Stundenzettel, wenn der Genehmigungsablauf eine Stufe Teamleiter, Projektmanager oder Aufgabenmanager enthält.
