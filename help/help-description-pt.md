O campo de Descrição disponibiliza uma área de texto formatado para adicionar notas, contexto ou documentação sobre este elemento. Pode usar formatação como negrito, itálico, listas e ligações. As descrições são visíveis para qualquer pessoa que tenha acesso à página de detalhes deste elemento. Ao passar o cursor sobre o nome de um projeto ou de uma tarefa noutros pontos da aplicação, também é apresentada a respetiva descrição.
