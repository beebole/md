Os Detalhes do campo personalizado definem o tipo de campo e as regras de validação para este campo. Consoante o tipo de campo (texto, número, data, data e hora, URL, booleano ou ID único), pode definir restrições como valores mínimos/máximos, valores permitidos, padrões de validação, texto indicativo e opções de formatação. Um campo ID único garante ainda que dois elementos nunca partilham o mesmo valor. Estas regras são aplicadas quando os utilizadores preenchem o campo.
