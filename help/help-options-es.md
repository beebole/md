La configuración de mostrar u ocultar controla qué ausencias, gastos, campos personalizados, proyectos y tareas están disponibles para esta entidad. Al ocultar los que no se aplican, simplifica la interfaz para que los usuarios solo vean las opciones relevantes para ellos. Esta configuración ayuda a adaptar la experiencia a distintos equipos o personas.
