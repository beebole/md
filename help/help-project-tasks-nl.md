In dit gedeelte ziet u alle actieve taken en boekingen die aan dit project zijn gekoppeld, gegroepeerd per planning. Voeg er hier een toe — een planning van het type Boekingen vraagt om een persoon en een periode, een planning van het type Taken om een naam — of verwijder een koppeling zonder de taak te verwijderen. Tijd die op een boeking wordt geregistreerd, gaat naar het project; tijd die op een taak wordt geregistreerd, blijft bij de taak.
