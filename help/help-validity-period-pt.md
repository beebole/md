O período válido para registo de tempo delimita quando o tempo pode ser registado, com uma data «De» e/ou «Até». Os registos fora desse período são recusados, e deixar uma data vazia mantém esse lado em aberto. Use-o para fechar um projeto concluído sem o arquivar, ou para refletir as datas de contrato de uma pessoa. Pode ser definido por pessoa, projeto ou etiqueta, prevalecendo o valor mais específico.
