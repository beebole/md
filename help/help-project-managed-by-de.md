Dieser Bereich zeigt, welche Personen dieses Projekt, diese Aufgabe oder diesen Tag verwalten. Von anderer Stelle geerbte Verantwortliche, etwa von einem übergeordneten Projekt, zeigen ihre Herkunft an und können nur dort entfernt werden. Verantwortliche können benachrichtigt werden, wenn das, was sie verwalten, erwähnt wird, und sie genehmigen Stundenzettel, wenn der Genehmigungsablauf eine Stufe für sie enthält, etwa Projektmanager oder Aufgabenmanager. Sie können hier direkt einen oder mehrere Verantwortliche zuweisen.
