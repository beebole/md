Le paramètre d'unités détermine si ce type d'absence est suivi en jours ou en heures. Vous pouvez également préciser si ce type d'absence est payé et donc inclus dans les coûts des personnes. Cela influe sur le calcul des contingents, des acquisitions et des rapports pour ce type d'absence.
