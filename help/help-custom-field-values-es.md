Los campos personalizados muestran los datos introducidos para cada campo personalizado asignado a esta entidad. Los campos aparecen aquí según su configuración de visibilidad y el tipo de entidad. Puede editar los valores directamente desde este panel y se validarán según las reglas definidas en la configuración del campo personalizado.
