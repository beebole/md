Los derechos de acceso controlan qué pueden ver y gestionar dentro de la aplicación los usuarios a los que se asigna este rol. Cada permiso puede configurarse de forma independiente para ver y para editar. Asigne este rol a las personas para concederles el acceso correspondiente en toda la plataforma.
