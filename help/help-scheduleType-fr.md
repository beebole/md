Cette section définit le modèle d'horaire de travail, notamment les jours travaillés et le nombre d'heures attendues par jour. Les horaires déterminent la base de référence pour les calculs de disponibilité, les contingents d'absence et la planification de la capacité. Plusieurs horaires peuvent être créés pour représenter différentes modalités de travail.
