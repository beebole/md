El período válido para registro de tiempo delimita cuándo se puede registrar tiempo, con una fecha «Desde» y/u «Hasta». Los registros fuera de ese período se rechazan, y dejar una fecha vacía mantiene ese lado abierto. Úsalo para cerrar un proyecto terminado sin archivarlo, o para reflejar las fechas de contrato de una persona. Puede definirse por persona, proyecto o etiqueta, y prevalece el valor más específico.
