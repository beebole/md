A definição de Unidades determina se este tipo de ausência é registado em dias ou em horas. Pode também indicar se o tempo deste tipo é pago e, por conseguinte, incluído nos custos das pessoas. Isto afeta a forma como os limites, as acumulações e os relatórios são calculados para este tipo de ausência.
