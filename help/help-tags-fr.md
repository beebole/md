La section Tags indique les tags auxquels cette entité appartient. L'association à un tag regroupe les entités pour partager des paramètres, du filtrage et du reporting. Tous les paramètres configurés sur un tag — tels que les horaires, les taux, les notifications ou l'approbation — sont hérités par chaque entité qui le porte. Ajoutez ou retirez des tags pour contrôler les groupes auxquels cette entité appartient ; retirer un tag hérité d'un projet ou d'une tâche parent ajoute ici une exclusion, affichée sous forme de badge hachuré rouge, que vous retirez pour récupérer le tag.
