Das Feld Beschreibung bietet einen Rich-Text-Bereich, um Notizen, Kontext oder Dokumentation zu dieser Entität hinzuzufügen. Sie können Formatierungen wie Fett, Kursiv, Listen und Links verwenden. Beschreibungen sind für alle sichtbar, die Zugriff auf die Detailseite dieser Entität haben. Wenn Sie an anderer Stelle in der App mit der Maus auf den Namen eines Projekts oder einer Aufgabe zeigen, wird auch die Beschreibung angezeigt.
