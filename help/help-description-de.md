Das Feld Beschreibung bietet einen Rich-Text-Bereich, um Notizen, Kontext oder Dokumentation zu dieser Entität hinzuzufügen. Sie können Formatierungen wie Fett, Kursiv, Listen und Links verwenden. Beschreibungen sind für alle sichtbar, die Zugriff auf die Detailseite dieser Entität haben.
