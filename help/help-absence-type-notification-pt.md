As definições de Notificações de ausência configuram os alertas relacionados com este tipo de ausência. Pode ativar avisos quando o saldo de uma pessoa passa a negativo, quando são feitos pedidos antecipados face aos saldos acumulados e quando este tipo de ausência é usado mais do que um número definido de vezes num mês ou num ano. Estas definições são guardadas, mas ainda não é enviado nenhum alerta.
