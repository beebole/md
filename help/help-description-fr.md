Le champ de description offre une zone de texte enrichi pour ajouter des notes, du contexte ou de la documentation à propos de cette entité. Vous pouvez utiliser une mise en forme telle que le gras, l'italique, les listes et les liens. Les descriptions sont visibles par toute personne ayant accès à la page de détail de cette entité. Survoler le nom d'un projet ou d'une tâche ailleurs dans l'application affiche aussi sa description.
