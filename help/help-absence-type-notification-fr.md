Les paramètres de notifications d'absence configurent les alertes liées à ce type d'absence. Vous pouvez activer des avertissements lorsqu'un solde passe en négatif, lorsque des demandes anticipées sont faites par rapport aux acquisitions, et lorsque ce type d'absence est pris plus d'un certain nombre de fois dans un mois ou une année. Ces paramètres sont enregistrés, mais aucune alerte n'est encore envoyée.
