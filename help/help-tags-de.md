Der Bereich Tags zeigt, zu welchen Tags diese Entität gehört. Durch das Taggen werden Entitäten für gemeinsame Einstellungen, Filterung und Berichte zusammengefasst. Alle für einen Tag konfigurierten Einstellungen – etwa Arbeitspläne, Sätze, Benachrichtigungen oder Genehmigungsworkflows – werden von jeder Entität geerbt, die ihn trägt. Fügen Sie Tags hinzu oder entfernen Sie sie, um zu steuern, zu welchen Gruppen diese Entität gehört; wenn Sie einen von einem übergeordneten Projekt oder einer übergeordneten Aufgabe geerbten Tag entfernen, wird hier stattdessen ein Ausschluss angelegt, angezeigt als rot schraffiertes Badge, das Sie entfernen, um den Tag zurückzuholen.
