La sección de etiquetas muestra a qué etiquetas pertenece esta entidad. El etiquetado agrupa entidades para compartir configuración, filtrar y generar informes. Cualquier configuración definida en una etiqueta —como horarios, tarifas, notificaciones o niveles de aprobación— se hereda en todas las entidades que la llevan. Añada o elimine etiquetas para controlar de qué grupos forma parte esta entidad; al eliminar una etiqueta heredada de un proyecto o una tarea superior, se añade aquí una exclusión, que se muestra como una insignia con rayas rojas y que puede eliminar para recuperar la etiqueta.
