La sección de etiquetas muestra a qué etiquetas pertenece esta entidad. El etiquetado agrupa entidades para compartir configuración, filtrar y generar informes. Cualquier configuración definida en una etiqueta —como horarios, tarifas, notificaciones o niveles de aprobación— se hereda en todas las entidades que la llevan. Añada o elimine etiquetas para controlar de qué grupos forma parte esta entidad.
