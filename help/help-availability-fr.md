Les paramètres d'affichage par défaut déterminent quels types d'entités et fonctionnalités sont visibles dans l'ensemble de l'organisation. Vous pouvez afficher ou masquer des modules tels que les projets, les tâches, les tags, les absences, les dépenses et les budgets. Masquer un module le retire de l'interface pour tous les utilisateurs de l'organisation.
