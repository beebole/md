Les paramètres d'affichage par défaut déterminent si chaque type d'élément est disponible par défaut pour tous les membres de l'organisation : projets, projets secondaires, tâches, absences, dépenses, plannings et champs personnalisés. Lorsqu'une option est décochée, ces éléments restent masqués jusqu'à ce que vous les accordiez individuellement, par élément sous Qui a accès ? ou par tag, personne ou projet sous Afficher ou masquer.
