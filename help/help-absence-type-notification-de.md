Die Einstellungen für Abwesenheitsbenachrichtigungen konfigurieren Warnungen zu dieser Abwesenheitsart. Sie können Warnungen aktivieren, wenn der Saldo einer Person ins Negative geht, wenn Anträge vorzeitig gegenüber den Ansprüchen gestellt werden und wenn diese Abwesenheitsart in einem Monat oder Jahr öfter als eine festgelegte Anzahl von Malen genommen wird. Diese Einstellungen werden gespeichert, es wird aber noch keine Benachrichtigung versendet.
