Dieser Bereich zeigt, mit welchen Projekten diese Aufgabe verknüpft ist. Durch die Verknüpfung einer Aufgabe mit einem Projekt werden die Zeiteinträge der Aufgabe für Berichte und Budgetverfolgung unter diesem Projekt zusammengefasst. Eine Aufgabe kann mit einem oder mehreren Projekten verknüpft werden. In einer Planung vom Typ „Buchungen“ wird eine Buchung nach ihrem Projekt und ihrer Person benannt.
