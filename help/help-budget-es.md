Los presupuestos le permiten fijar objetivos económicos o de tiempo para este proyecto durante un periodo definido. Puede hacer un seguimiento de las horas, la facturación o el coste frente al presupuesto y repartir las asignaciones por persona o por proyecto. El progreso del presupuesto se calcula automáticamente a partir de las entradas de tiempo registradas y los gastos.
