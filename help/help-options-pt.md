As definições de Mostrar ou ocultar controlam quais os tipos de ausência, tipos de despesa, campos personalizados, projetos e tarefas disponíveis para este elemento. Ao ocultar os que não se aplicam, simplifica a interface para que os utilizadores vejam apenas as opções que lhes são relevantes. Estas definições ajudam a adaptar a experiência a diferentes equipas ou indivíduos.
