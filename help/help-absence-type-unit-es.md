La unidad determina si este tipo de ausencia se contabiliza en días o en horas. También puede especificar si el tiempo de este tipo está pagado y, por tanto, se incluye en los costes de personas. Esto afecta a cómo se calculan las asignaciones, los devengos y los informes para este tipo de ausencia.
