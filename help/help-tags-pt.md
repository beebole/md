A secção Etiquetas mostra a que etiquetas este elemento pertence. Etiquetar agrupa elementos para definições, filtragem e relatórios partilhados. Quaisquer definições configuradas numa etiqueta — como horários, tarifas, notificações ou fluxo de aprovação — são herdadas por todos os elementos que a possuem. Adicione ou remova etiquetas para controlar de que grupos este elemento faz parte.
