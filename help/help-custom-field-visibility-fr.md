La visibilité du champ personnalisé contrôle l'endroit où ce champ apparaît dans l'application. Vous pouvez le rendre visible sur les profils des personnes, sur les enregistrements de temps (filtrés par catégorie de projet, catégorie de tâche ou type d'absence), sur les projets et sur les tâches. Cela vous permet de n'afficher les champs pertinents que dans les contextes où ils sont nécessaires.
