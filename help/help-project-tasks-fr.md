Cette section liste toutes les tâches et réservations actives liées à ce projet, regroupées par planification. Ajoutez-en une directement ici — une planification de type Réservations demande une personne et une période, une planification de type Tâches demande un nom — ou retirez un lien sans supprimer la tâche. Le temps saisi sur une réservation est attribué au projet ; le temps saisi sur une tâche reste sur la tâche.
