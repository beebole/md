Esta sección muestra qué personas gestionan este proyecto, tarea o etiqueta. Los responsables heredados de otro nivel, como un proyecto padre, indican de dónde proceden y solo pueden quitarse allí. Los responsables pueden recibir notificaciones cuando se menciona lo que gestionan, y aprueban las hojas de tiempo cuando el flujo de aprobación incluye una etapa para ellos, como Jefes de proyecto o Responsables de las tareas. Puede asignar uno o varios responsables directamente desde aquí.
