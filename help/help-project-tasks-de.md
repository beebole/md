Dieser Bereich listet alle aktiven Aufgaben und Buchungen auf, die mit diesem Projekt verknüpft sind, gruppiert nach Planung. Fügen Sie sie direkt hier hinzu — eine Planung vom Typ Buchungen fragt nach einer Person und einem Zeitraum, eine Planung vom Typ Aufgaben nach einem Namen — oder entfernen Sie eine Verknüpfung, ohne die Aufgabe zu löschen. Auf einer Buchung erfasste Zeit wird dem Projekt zugerechnet; auf einer Aufgabe erfasste Zeit bleibt bei der Aufgabe.
