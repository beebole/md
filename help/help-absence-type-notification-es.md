La configuración de notificaciones de ausencias define las alertas relacionadas con este tipo de ausencia. Puede activar avisos cuando el saldo de una persona pase a negativo, cuando se realicen solicitudes anticipadas frente a los devengos y cuando se detecten ocurrencias en exceso. Cada notificación puede ajustarse por frecuencia e intervalo.
