La configuración de notificaciones de ausencias define las alertas relacionadas con este tipo de ausencia. Puede activar avisos cuando el saldo de una persona pase a negativo, cuando se realicen solicitudes anticipadas frente a los devengos y cuando este tipo de ausencia se tome más de un número determinado de veces en un mes o un año. Esta configuración se guarda, pero todavía no se envía ninguna alerta.
