Los detalles del campo personalizado definen el tipo y las reglas de validación de este campo. Según el tipo de campo (texto, número, fecha, fecha y hora, URL, booleano o ID único), puede establecer restricciones como valores mínimos y máximos, valores permitidos, patrones de validación, texto de marcador de posición y opciones de formato. Un campo ID único garantiza además que dos elementos no compartan el mismo valor. Estas reglas se aplican cuando los usuarios rellenan el campo.
