Los detalles del campo personalizado definen el tipo y las reglas de validación de este campo. Según el tipo de campo (texto, número, fecha, URL, booleano o fecha y hora), puede establecer restricciones como valores mínimos y máximos, valores permitidos, valores predeterminados y opciones de formato. Estas reglas se aplican cuando los usuarios rellenan el campo.
