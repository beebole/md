Esta secção (Detalhes) define o padrão do horário de trabalho, incluindo quais os dias de trabalho e quantas horas são previstas por dia. Os horários determinam a base de referência para os cálculos de disponibilidade, os limites de ausência e o planeamento de capacidade. Podem ser criados vários horários de trabalho para representar diferentes regimes de trabalho.
