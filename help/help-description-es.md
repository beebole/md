El campo de descripción ofrece un área de texto enriquecido para añadir notas, contexto o documentación sobre esta entidad. Puede usar formato como negrita, cursiva, listas y enlaces. Las descripciones son visibles para cualquier persona que tenga acceso a la página de detalles de esta entidad.
