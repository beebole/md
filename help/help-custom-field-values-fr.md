Les champs personnalisés affichent les données saisies pour chaque champ personnalisé attribué à cette entité. Les champs apparaissent ici en fonction de leurs paramètres de visibilité et du type d'entité. Vous pouvez modifier les valeurs directement depuis ce panneau ; elles seront validées selon les règles définies dans la configuration du champ personnalisé.
