Esta secção (Projetos) mostra a que projetos esta tarefa está associada. Associar uma tarefa a um projeto agrupa os registos de tempo da tarefa sob esse projeto para fins de relatório e de acompanhamento do orçamento. Uma tarefa pode estar associada a um ou mais projetos.
