**Was es macht**

Arbeitsplan-Zuweisungen funktionieren bereits für Ihre Organisation und Personen. Mit **Erweiterten Tags** weisen Sie allen, die einen Tag teilen, in einem Schritt einen Arbeitsplan zu.

**Warum Sie es nutzen sollten**

- **Schnell ausrollen** — wenden Sie einen Arbeitsplan in einer einzigen Aktion auf ein ganzes Team an.
- **Einheitliche Kapazität** — halten Sie die Arbeitszeiten innerhalb einer Gruppe im Einklang.
- **Leicht anpassbar** — aktualisieren Sie Gruppen-Arbeitspläne sofort, wenn sich Richtlinien ändern.

---

Verfügbar im **Advanced**-Tarif — oder fügen Sie das Add-on **Benutzerdefinierte Felder, benutzerdefinierte Rollen und erweiterte Konfiguration** zum **Essential**-Tarif hinzu.
